# About

Arkiri 是一个用 Astro 构建的个人博客。界面在一个开源 Astro 博客模板的基础上，按 endfield-ui 的视觉语言重做；模板来源与致谢写在仓库 README 里。正文使用 HarmonyOS Sans，界面西文使用自托管的 Saira。
