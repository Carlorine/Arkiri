这是一篇排版样本，也是一份写作速查。每一节先展示实际效果，再在必要的位置给出对应写法。文章使用当前站点已启用的语法，不包含需要额外插件的 Pandoc 表格或定义列表。

你可以通过右侧目录跳转，切换明暗主题，或缩小窗口，观察同一份内容在不同阅读条件下的表现。页面顶部的文章名就是唯一的一级标题，正文从二级标题开始。

## 标题层级

二级标题用于组织文章的主要章节。标题应该描述这一节的内容，不必同时充当口号、装饰线和段落摘要。

### 三级标题：一个具体步骤

三级标题进一步拆分当前章节。例如，在“发布文章”中单独说明“检查图片”。

#### 四级标题：步骤中的说明

较深的层级适合补充说明，不建议在短文章中连续使用太多层。

##### 五级标题：细节示例

这一行用于观察五级标题的字号、字重与间距。

###### 六级标题：最深层级

这一行用于观察六级标题。常规文章通常使用二级和三级标题就足够了。

```markdown
## 标题层级
### 一个具体步骤
#### 步骤中的说明
##### 细节示例
###### 最深层级
```

## 段落、换行与中英混排

写作时，先用一句话交代背景，再展开具体信息。这里是一段中文正文：它应该有清晰的行距、自然的换行和稳定的阅读宽度，而不是通过大块底色吸引注意。

这是第二个段落。两个段落之间用一个空行分隔；同一段内部的源文件换行，并不等于另起一段。

Markdown lets content stay readable in plain text. 在中文段落里插入 Astro、TypeScript 和 CSS 时，可以观察英文字体、标点与中文基线是否协调。数字也需要清晰：2026 年 10 月 22 日，版本 v1.2.0，文件大小 128 KB，完成度 75%。

这一行与下一行属于同一段，但在行末使用反斜线强制换行。\
这是强制换行后的第二行。

```markdown
这是第一段。

这是第二段。

需要明确换行时，在行末加入反斜线。\
下一行仍属于同一段。
```

## 文字强调与行内代码

普通文字负责承载主要内容，**加粗文字**标记关键概念，*斜体文字*用于强调语气，***粗斜体***用于演示组合效果。~~删除线~~表示已经废弃的说法，不应与当前有效的操作混在一起。

使用 `pnpm build` 表示命令，使用 `src/content/posts/` 表示路径，使用 `title: "一篇新文章"` 表示一小段配置。行内代码应保持在正文行中，不应像独立卡片一样抢占阅读节奏。

转义后可以直接展示语法符号：\*这不是斜体\*、\[这不是链接\]、\# 这不是标题。需要在行内代码中包含反引号时，可以写成 ``代码中的 ` 符号``。

```markdown
**加粗**、*斜体*、***粗斜体***、~~删除线~~
`pnpm build`
\*这不是斜体\*
```

## 链接与文内跳转

链接文字应该说明目标，例如[返回首页](/)、[查看归档](/archive/)和[阅读扩展组件示例](/posts/markdown-extended/)。

长文章可以使用[文内跳转，回到“标题层级”](#标题层级)。同一个目标重复出现时，也可以使用[引用式链接][archive]，把地址集中写在文末。

下面是可直接识别的地址形式：<https://example.com>。示例域名仅用于展示地址排版。

```markdown
[返回首页](/)
[文内跳转](#标题层级)
[引用式链接][archive]

```

## 列表与嵌套

### 无序列表

- 标题简洁，能够说明文章主题。
- 正文分段，一段围绕一个主要意思展开。
- 图片有替代文字，链接有明确的目标描述。

### 有序列表

1. 在文章目录中新建 Markdown 文件。
2. 填写标题、发布日期和分类。
3. 编写正文，在本地预览后再发布。

### 嵌套列表与段落

1. 准备内容。
   - 确认标题与摘要。
   - 检查素材。
     - 图片是否清晰。
     - 图片来源是否已经注明。
2. 检查阅读体验。

   这是第二项中的补充段落。它仍然属于这一项，应与列表正文对齐，不应退回到文章左边缘。

3. 完成发布。

### 任务列表

任务列表展示文档中的完成状态，下面的复选框不是交互表单。

- [x] 检查标题层级。
- [x] 确认示例表格正常渲染。
- [ ] 补充自己的文章内容。

```markdown
- 无序列表
  - 嵌套项目

1. 有序列表
2. 下一步

- [x] 已完成
- [ ] 待完成
```

## 引用与嵌套引用

> 好的示例应该帮助读者理解一种写法，同时让维护者看见它的边界。
>
> 这是同一段引用中的第二个段落。引用中也可以包含**强调**、`行内代码`和[链接](/archive/)。

引用也可以分层：

> 第一层引用交代背景。
>
> > 第二层引用补充原文中的一段话。
>
> 回到第一层，继续说明这段话与当前内容的关系。

```markdown
> 第一段引用。
>
> 第二段引用。
>
> > 嵌套引用。
```

## 代码块与预格式文本

### 带语言标记的代码

下面是一段可以复制的 TypeScript。中文注释与英文代码放在同一个示例中，方便检查等宽字体与复制结果。

```ts
// 把标题转换为文章列表中的显示文字。
function formatTitle(title: string, index: number): string {
  return `${index + 1}. ${title.trim()}`;
}

console.log(formatTitle("Markdown 与基础排版", 0));
```

### 纯文本与空白保留

不需要语法高亮时，使用纯文本代码块。下面的空行、缩进和列间空格都应得到保留。

```text
article/
  index.md
  cover.png

状态    内容
ready   标题、正文、图片
```

### 长行

较长的代码或地址用于检查代码块的边界。它不应撑宽整篇文章；根据代码块当前设置，长行可以在块内换行或横向滚动。

```text
https://example.com/articles/markdown-basics?theme=light&language=zh-CN&section=code-blocks&preview=true&preserve-formatting=true
```

行号、差异标记和折叠等更完整的能力，见[代码功能示例](/posts/expressive-code/)。

## 数学公式

行内公式用于句子中的简短表达，例如圆的面积为 $A = \pi r^2$，勾股定理为 $a^2 + b^2 = c^2$。

独立公式用于需要单独阅读的推导或等式：

$$
\frac{1}{n}\sum_{i=1}^{n} x_i = \bar{x}
$$

下面的对齐公式展示多行排版：

$$
\begin{aligned}
f(x) &= x^2 + 2x + 1 \\
     &= (x + 1)^2
\end{aligned}
$$

```latex
行内公式：$A = \pi r^2$

独立公式：
$$
\frac{1}{n}\sum_{i=1}^{n} x_i = \bar{x}
$$
```

## 脚注与补充说明

脚注把补充内容放在文末，避免在正文中插入过长的解释。这里是第一个脚注[^layout]，这里是第二个脚注[^syntax]。也可以再次引用同一条脚注[^layout]。

```markdown
正文中的说明[^note]。

[^note]: 放在文末的补充内容。
```

## 少量 HTML 排版补充

以下元素使用原生 HTML，并不是额外的 Markdown 简写。键盘提示可写为 <kbd>Ctrl</kbd> + <kbd>S</kbd>，化学式可写为 H<sub>2</sub>O，平方可写为 x<sup>2</sup>。

<details>
<summary>展开一段补充说明</summary>

这里是折叠区域中的正文。可以使用**加粗文字**、[站内链接](/archive/)和普通段落。

- 这是一条补充信息。
- 使用鼠标点击或键盘操作标题，可以展开和收起这部分内容。

</details>

```html
<kbd>Ctrl</kbd> + <kbd>S</kbd>
H<sub>2</sub>O 与 x<sup>2</sup>
```
